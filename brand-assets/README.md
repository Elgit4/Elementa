# Elementa brand assets

These are the **approved Elementa logo files** used by the application. The original files are also copied into `public/` because Vite serves assets from that directory.

## Where the files are used

| File | Purpose |
|---|---|
| `elementa-logo.png` | Full logo for headers and brand placement |
| `elementa-symbol.png` | App icon, navigation mark, favicon and installed-app icon |

The PNGs are the approved artwork. Do not recreate, recolour, redraw or substitute another logo. Use the symbol-only crop when the available space cannot accommodate the wordmark or tagline.
